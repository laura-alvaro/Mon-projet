# Dossiers clients

Un dossier par client, créé avec `bash outils/nouveau-dossier.sh vendeur NOM Ville` (ou `acquereur NOM`).
Les dossiers clients ne sont **pas** envoyés sur GitHub (RGPD) : seuls les modèles le sont.
Pensez à sauvegarder ce dossier ailleurs (Google Drive, disque externe chiffré) ou à le garder sur votre ordinateur.
