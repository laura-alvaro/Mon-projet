# Checklist dossier VENDEUR

> Cocher `[x]` + date de réception + date de fin de validité. Vérifier les règles en vigueur au moment de la vente.

## 1. Identité & KYC (LCB-FT) — `01_identite_kyc`
- [ ] Pièce d'identité de chaque propriétaire (recto/verso, en cours de validité)
- [ ] Justificatif de domicile
- [ ] Situation familiale : livret de famille / contrat de mariage / PACS / jugement de divorce
- [ ] Si société (SCI) : Kbis, statuts, PV autorisant la vente, identité du gérant, bénéficiaires effectifs
- [ ] Si succession : attestation de dévolution / acte de notoriété, coordonnées du notaire
- [ ] Fiche de vigilance LCB-FT IAD complétée

## 2. Mandat — `02_mandat`
- [ ] Mandat de vente signé par tous les propriétaires (n° de registre : ______)
- [ ] Type : simple / exclusif / semi-exclusif — date de fin : ______
- [ ] Bordereau de rétractation (si signé hors établissement / à distance)
- [ ] Avis de valeur remis au vendeur

## 3. Propriété & bien — `03_titre_propriete`
- [ ] Titre de propriété (acte d'achat, donation, attestation de propriété)
- [ ] Dernier avis de taxe foncière
- [ ] Plans du bien / plan cadastral
- [ ] Permis de construire, déclaration préalable, certificat de conformité (travaux, extension, piscine, véranda)
- [ ] Factures et garanties décennales des travaux de moins de 10 ans
- [ ] Contrat d'entretien chaudière / pompe à chaleur, ramonage
- [ ] Factures énergie (pour cohérence DPE) — facultatif
- [ ] Servitudes, bornage (maison / terrain)
- [ ] Bail en cours + quittances (si vendu loué), dépôt de garantie

## 4. Diagnostics (DDT) — `04_diagnostics`
| Diagnostic | Concerné si | Validité | Reçu le | Valable jusqu'au |
|---|---|---|---|---|
| DPE | Toujours (dès l'annonce) | 10 ans (attention anciens DPE) | | |
| Audit énergétique | Maison / monopropriété classée E, F, G | 5 ans | | |
| Amiante | Permis avant 01/07/1997 | Illimitée si absence | | |
| Plomb (CREP) | Construit avant 1949 | 1 an si présence, illimité sinon | | |
| Électricité | Installation > 15 ans | 3 ans | | |
| Gaz | Installation > 15 ans | 3 ans | | |
| Termites | Zone arrêté préfectoral | 6 mois | | |
| ERP (État des risques) | Toujours | 6 mois | | |
| Assainissement non collectif | Fosse / micro-station | 3 ans | | |
| Mérules | Zone arrêté préfectoral | Information | | |
| Bruit (plan d'exposition) | Zone aéroport | — | | |
| Mesurage Carrez | Lot de copropriété | Sans limite si pas de travaux | | |

## 5. Copropriété — `05_copropriete`
- [ ] Règlement de copropriété + état descriptif de division + modificatifs
- [ ] 3 derniers PV d'assemblée générale
- [ ] Fiche synthétique de la copropriété
- [ ] Carnet d'entretien
- [ ] Pré-état daté (ou état daté demandé au syndic)
- [ ] Montant des charges courantes (2 derniers exercices) + fonds de travaux
- [ ] Diagnostic technique global (DTG) / Plan pluriannuel de travaux (PPPT) si existant
- [ ] Coordonnées du syndic

## 6. Marketing — `06_photos` · `07_videos` · `08_annonce`
- [ ] Photos prises → retouchées
- [ ] Vidéo / Reel
- [ ] Annonce rédigée et vérifiée (mentions obligatoires)
- [ ] Annonce publiée (date) : ______

## 7. Visites & offres — `09_visites_offres`
- [ ] Bons de visite signés
- [ ] Comptes-rendus de visite envoyés au vendeur
- [ ] Offre(s) d'achat écrite(s) + attestation de financement de l'acquéreur
- [ ] Acceptation écrite du vendeur

## 8. Compromis & notaire — `10_compromis_notaire`
- [ ] Coordonnées des notaires (vendeur / acquéreur)
- [ ] Dossier complet transmis au notaire (date) : ______
- [ ] Compromis signé (date) — fin de rétractation : ______
- [ ] Fin de condition suspensive de prêt : ______
- [ ] Acte authentique (date) : ______ — honoraires encaissés : ☐
